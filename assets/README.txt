ASSETS FOLDER
=============

Place a custom icon file here if desired:
  - Name it: icon.ico
  - The create-shortcut.ps1 script will use it automatically for the desktop shortcut.

If no icon.ico is present, the shortcut will use the default Windows shell icon.

You can convert any PNG to ICO using free tools like:
  - https://convertio.co/png-ico/
  - IrfanView (free, Windows)
  - GIMP (free, open source)
